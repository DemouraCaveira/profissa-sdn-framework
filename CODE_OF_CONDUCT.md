# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expectativas
- Seja respeitoso, inclusivo e colaborativo.
- Aponte problemas de forma construtiva.
- Respeite diferentes perspectivas e experiências.

## Comportamentos inaceitáveis
- Assédio, discriminação ou linguagem ofensiva.
- Ameaças ou intimidação.
- Compartilhamento de informação privada sem permissão.

## Aplicação
- Violações podem resultar em avisos ou restrições de participação.
